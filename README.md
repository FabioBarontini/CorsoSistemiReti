# Atlante della Rete — V4

Apri `index.html` come pagina iniziale.

Le pagine principali sono:
- `timeline.html`
- `album.html`
- `lezione-http.html`
- `lezione-rest.html`

IMPORTANTE: mantieni l'intera cartella estratta, compresa la cartella `assets`.
Le pagine usano `assets/atlas.css` e `assets/atlas.js`.
Se il file HTML viene copiato da solo, il browser non potrà caricare la grafica e le animazioni.

## V10 — Distretto Sicurezza
- `security.html`: sezione narrativa Netopolis con sei quartieri, approfondimenti tecnici e laboratori.
- La palette della sezione sicurezza è volutamente diversa: borgogna/rosso scuro, ambra e verde-petrolio.
- Le 13 figurine hanno ora ritratti SVG locali, quindi non dipendono da immagini remote e non mostrano più icone rotte quando il sito viene aperto offline.
